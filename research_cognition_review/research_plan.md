# Cognition Architecture Review Plan

Date: 2026-09-11

Question: Does the proposed cognitive state architecture address the observed
failures, and which claims lack evidence or confuse implementation defects with
research problems?

## Local Investigation

- Read the full whitepaper and required provenance documents.
- Verify prompt duplication, run records, and harness boundaries without changing
  the source database or archived project.
- Check graph input contracts and current invariants before proposing new objects.

## Delegated Research

1. Working sets: primary-source precedents for context selection, externalized
   artifacts, paging, and step-specific inputs. Separate existing mechanisms from
   unresolved optimal selection.
2. Attribution: primary-source precedents for optimizing multi-stage language
   model programs. Separate failure localization, causal attribution, and useful
   black-box optimization.
3. Cross-run experience: primary-source precedents for retaining, selecting,
   evaluating, and retiring procedural experience. Identify transfer limitations.

Each research task uses 3-5 web searches and writes a separate findings file,
including source URLs and limitations. No agent edits source or archive files.

## Synthesis

Produce A-G judgments with whitepaper subsection references. Distinguish verified
local facts, unsupported causal claims, research precedents, and proposed tests.
Prioritize minimal experiments on the existing harness over architecture expansion.
