# P3 决定：停止扩展认知 schema

`DEVELOPMENT_PLAN.md` 的 P3 是一项**可选**实验，其退出判据写在它自己的第 5 条：

> **如果没有独立行为收益，停止扩展认知 schema。**

实验已跑（在计划成形之前，见 `experiments/cognition_takeover/`），结论是**没有独立行为收益**。
所以本文件执行第 5 条。

## 证据

三项实验，同一真实 run 的同一真实切点（`f4eb8ac7`，首次写作之前，13 轮检索之后）。

### ① 考卷：七问判据

| 条件 | 材料规模 | 三次得分 | 均值 |
| --- | ---: | --- | ---: |
| A 原始材料 | 141,033 字符 | [15, 20, 18] | 17.7 |
| S 结构化摘要 | 5,045 字符 | [6, 6, 9] | 7.0 |
| B 认知状态 | 4,762 字符 | [22, 21, 18] | 20.3 |

S 与 B 由**同一模型从同一材料生成**，规模几乎相同。结论：**同样尺寸下 schema 决定一切**（3 倍），
而认知状态用 3.4% 的体积达到或超过原始材料（区间重叠，故这条是弱信号）。

### ② 行为测试：让接任者真的写

判据换成**交付物要求**（与七问判据不同，以此打破循环性）：**三个条件都满足全部 5 项。**

> **考卷 7/31 的条件，写出的论文与满分条件同样合格。**
>
> **七问判据测的是能否复述任务，不是能否完成任务。**

### ③ 取回设计

状态固定，只换取回机制：

| 机制 | 合计 billed | 结果 |
| --- | ---: | --- |
| 材料进 prompt | 100,305 | 5/5 |
| 分页取回（累积） | 74,650 | 5/5 |
| 子调用取回（不累积） | 337,324 | 5/5 |

**结论不是"不累积就好"**：子调用接口没有**选择**能力，于是代理只能把整本账本分块问完。
**接口的形状决定了对象读多少**——必须"先选择，再交给模型"。

### ④ 为什么形状不重要

因为 **Anchor 的节点本来就是"每次全新投影"**：累积在工件里，不在上下文里；重试不重放历史。

> **认知层想做的事，Anchor 已经在做——只是声明的粒度粗。**

## 决定

```
停止扩展认知 schema。

理由不是"状态无用"，而是：
  · 状态单独不产生价值（实验 ① 与 ②）
  · 它的形状不改变产出（实验 ②）
  · 成本的杠杆是【前缀稳定性】与【选择】，不是状态的丰富度（实验 ③ 与 §2.4.1）

而 §7 已经把"自动 cognition projection"排除在当前批次之外——本决定与之一致。
```

## 仍然要做的事（不属于 schema 扩展）

① 声明的粒度            403K 里 34.92% 是重复 → 已修（cedd62f）
② 节点【内】工具循环增长   现靠静态上限，非压缩

## 什么证据会推翻这个决定

写清楚，否则这是一个不可证伪的结论：

```
· 一个【多次交接】的任务（N ≥ 10 次压缩），其中认知状态不退化而摘要链退化
  —— 本次实验只有【一次】交接，而架构的原始主张是关于【累积】的
· 一个受控 selector，能证明"先选择再读取"在真实任务上降低错误决策或重复失败
  —— 这是实验 ③ 指出但未实现的东西
· 一种任务，其细节无法按需取回（跨系统、需人工、付费），使"状态自足"成为必需
```

**在此之前，扩展 schema 是在没有证据的条件下增加表面积。**

## 与计划其余部分的关系

P3 的结论**不阻塞**任何已完成的切片：P0–P2 全部与状态无关（执行、恢复、失败传播、回放、
遥测、缓存、策略、文档）。**认知层从来不是 Runtime 的依赖，本决定确认了这一点。**
