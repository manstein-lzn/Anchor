# 长会话运行详情超时修复

## 问题与修复

运行详情曾为每个 invocation 重复展开此前恢复的完整 Session 历史。长会话因此产生重复消息、过大的响应与对象分配，同步读取和序列化也会占用异步 worker。前端请求失败时丢弃错误，导致页面显示空画布。

本次修复让 Run 详情仅投影各 invocation 的本轮通知，活动工具进度及原有工具记录回退保持；完整会话读取仍包含恢复历史。详情读取、投影和最终 JSON 序列化移入 blocking pool。前端明确显示加载、错误和重试，列表刷新不取消在途详情，刷新失败保留已有内容，切换 Run 忽略旧响应。活动 Run 每三秒刷新且不重叠请求，结束时补读最终详情；非活动且摘要未变的 Run 不重复读取。

## 验证范围

已部署候选的只读规模验收覆盖 301 个 invocation：详情约 6.79 MB，线上请求约 3.6 秒返回；同时发出的健康请求均成功，最长约 8 毫秒。浏览器确认运行画布和节点对话可打开，无页面错误。未调用真实模型或发送业务消息。

这些指标来自部署候选，与本 PR 在最新主分支上的回归分开记录；它们不代表全员并发或未来更长会话的压力保证。

独立 PR 分支基于主分支 `f5f5dfe3` 验证，包含累计历史去重、完整历史保留、活动工具进度、工具记录回退、身份校验、详情 HTTP 格式，以及加载/失败/重试和旧请求晚到的回归。

- Trace 与 live 回归 16 项、Run API 4 项、详情应用服务 4 项通过。四项架构围栏共 7 项通过。
- Web 49 个测试文件、384 项测试通过，类型检查及生产构建通过。
- 浏览器隔离回归 1 项通过：从图编排打开延迟详情，列表刷新不打断请求，错误提示可见，重试成功显示运行画布。
- Rust 格式检查及常规 Clippy 通过；Clippy 保留既有 49 条告警。

本次整理没有重跑完整 Rust 工作区；上述规模指标来自部署候选，不冒充该分支的新一轮生产验收。原始候选全量测试有环境缺口，不能视为完整通过。

## 未覆盖边界

旧 evidence 仍包含累计历史。当前 reader 跳过它的嵌套 JSON 对象分配，但仍须读取并扫描原始字节；持久文件增长与未来更长历史的读取复杂度尚未消除。没有增加第二份持久历史，也没有延长浏览器请求超时。

原始用户记录、截图、部署配置和机器现场不随 PR 发布。
