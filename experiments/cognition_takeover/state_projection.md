# 任务认知

## Contract

**目标**：产出一篇面向读者的中文学术综述，主题是「编译器优化中的代价模型（cost model）近年的发展」。

**读者**：懂机器学习与系统、但不在编译器优化细分领域的工程师与研究者。

**范围之外**：
- 非编译器领域的代价模型——数据库查询优化、网络、纯硬件功耗——除非方法明确迁移到编译器优化并给出编译器场景实验
- 无定量实验的观点文、演示系统介绍、博客、厂商材料
- 非英文文献
- 无法获取全文（仅摘要、且无公开版本）的文献

**交付要求**：基于论文正文而非摘要；清晰的论证主线；机制层面的演化解释；代表性方法的对比表；把相互冲突的证据摆出来；结尾给出可操作的开放问题。

## Situation

**已确立**
- 59 篇来源通过验证；其中 **24 篇读过全文**，28 篇仅摘要级，7 篇仅题录级
- 13 轮检索后账本收敛
- 领域演化在**三个层次**上都成立，且各有自己的表示与监督信号：
  - **指令级**：表示从 token 序列（Ithemal，层次 LSTM）推进到指令依赖图（GRANITE，GNN）；监督信号是真实硬件实测吞吐
  - **张量/循环程序**：表示从「AST 特征 + 硬件专家特征」转向「调度原语序列」；监督信号是实测性能，问题因此变成「样本要多少、怎么选」
  - **编译遍决策**：以调用图/调用点为状态、二进制体积为奖励训练策略网络（MLGO 进入 LLVM 主干）；或以学习到的二级代价模型替代不可即时计算的运行时奖励

**相互冲突**
- 核心冲突不是「谁更准」，而是**精度与可移植性/成本的分工冲突**：
  - 学习型：精度上有可量化优势，但依赖逐微架构的大规模真机测量语料与长时训练，跨平台迁移差，且离线数据采集成本高
  - 解析式：在推理成本、可解释性、跨平台可移植性上反击，并有工作公开主张「快、准确且可解释」可同时满足
  - 直接量化对照显示两者在少量模型上**互有胜负**，且静态方案把调优时间开销大幅压低
- 该冲突目前**未被解决**，是论文要呈现的核心张力

**受阻或薄弱**
- **编译遍决策层次**的证据最薄
- 部分谱系的前向引用追踪尚未完成（如某些工作的后续工作）

## Experience

**不可重复的失败路径**
- **宽泛关键词**在 arXiv 全文索引上噪声极高：有一轮检索返回结果全部为深度学习理论、证据深度学习、空气污染预测等无关文献，被**整轮否决**
  - **重试条件**：改用机制性关键词——工具名与数据集名（Ithemal / BHive / AutoTVM / MLGO 等），而非概念性描述
  - 完整的检索与纳排记录在检索日志中（74 条）
- 早期版本曾把可量化的断言建立在**摘要复述**上，被确定性检查拒绝
  - **重试条件**：该来源先取得全文并由采集器确认，再引用其数字

**仍然是约束的教训**
- 只有摘要级证据的来源**不得用于支撑结果型数字**
- 引用完整性必须在写作前成立，不是写作后补
