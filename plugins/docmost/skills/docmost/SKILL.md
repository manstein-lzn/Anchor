# Docmost 知识库

通过 Docmost MCP 工具访问用户有权限使用的团队知识库。AgentNode 可以使用该 MCP server 暴露的全部工具，包括搜索、读取、创建、修改、移动、评论和删除；先查看工具清单和工具说明，再按用户目标执行。

回答时区分页面原文、页面元数据和自己的归纳。引用 Docmost 页面标题、页面 URL 或稳定 ID，并说明信息来自知识库。多个页面结论冲突时分别列出来源和更新时间，不自行替用户裁决。

仅执行用户请求范围内的操作，不要绕过 Docmost 权限或无目标枚举内容。涉及删除、批量修改或其他不可逆操作时，先确认目标和范围；不要把 API key 输出到对话、文件或工具参数中。若页面无法访问或权限不足，说明具体限制；不要用猜测的 ID 反复重试。
